# Deskripsi Aplikasi

Aplikasi Pengelolaan Kegiatan Kelas merupakan aplikasi sederhana berbasis web yang digunakan untuk menampilkan dan mengelola daftar kegiatan kelas menggunakan HTML, CSS, dan JavaScript.

# Fitur Aplikasi

1. Menampilkan daftar kegiatan kelas.
2. Menambahkan kegiatan baru.
3. Mencegah penambahan kegiatan yang kosong atau duplikat.
4. Mencari kegiatan berdasarkan nama.
5. Menghapus kegiatan dari daftar.
6. Menghitung jumlah kegiatan secara otomatis.

# Teknologi yang Digunakan

- HTML untuk struktur halaman.
- CSS untuk mengatur tampilan aplikasi.
- JavaScript untuk mengelola data dan menjalankan fitur aplikasi.
